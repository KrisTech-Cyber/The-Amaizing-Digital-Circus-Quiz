# 🎪 The Amazing Digital Circus Quiz

🎩 A Python-based interactive quiz inspired by *The Amazing Digital Circus (TADC)*

---

## 📌 About the Project
This is a simple terminal-based quiz game built in Python.  
It tests your knowledge of *The Amazing Digital Circus* characters and themes, while adding a bit of chaotic “Caine-style” personality throughout the experience.

This project was built while following a Python learning tutorial by TechWithTim (https://youtu.be/NpmFbWO6HPU) and experimenting with basic programming concepts.

---

## 🧠 What I Learned
Through this project, I practiced and improved my understanding of:

- 🐍 Python `if / else` statements  
- 🎯 User input handling  
- 📊 Score tracking using variables  
- 🔁 Basic program flow and logic  
- 🎭 Adding personality and text-based storytelling in code  

---

## 🎮 How It Works
- The game asks the player a series of questions  
- Each correct answer increases the score  
- At the end, the final score is displayed as a percentage  
- The quiz is themed around *The Amazing Digital Circus*
